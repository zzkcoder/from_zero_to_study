### 简答题

* `list`、`tuple`、`set`、`dict` 四个容器各自最核心的特点是什么？分别适合什么场景？

```py
list：有序、可重复、可变，适合按索引访问、遍历、栈。

tuple：有序、可重复、不可变，适合固定结构、函数返回多值、可作 dict key。

set：无序、不重复、可变，适合去重、成员检测、集合运算。

dict：键值映射、键唯一、可变，适合通过 key 快速查找 value
```

* 分别列举 Python 中常见的不可变类型和可变类型，各至少 3 个

```py
不可变类型：int、float、str、tuple、bool、frozenset。
可变类型：list、dict、set、自定义对象等
```

* 浅拷贝和深拷贝的区别是什么？`a[:]` 对列表来说属于哪一种？

```
浅拷贝只复制最外层对象，内部嵌套对象仍然共享。深拷贝递归复制所有层。a[:] 对列表是浅拷贝
```

* Python 容器什么时候用 `list`？什么时候用 `set`？

```
用 list：需要顺序、允许重复、需要索引、经常遍历、当栈用。

用 set：需要去重、判断元素是否存在、做交集并集差集，不关心顺序。
```



* dict` 底层解决的核心问题是什么？为什么它平均查找是 O(1)？

```
dict 底层解决的是“通过 key 快速找到 value”的问题。它使用哈希表，把 key 通过哈希函数映射到位置，平均情况下插入、删除、查找都是 O(1)。冲突时通过开放寻址或链表等方式处理。
```
