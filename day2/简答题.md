1.Python 函数参数中，位置参数、关键字参数、默认参数、可变位置参数、可变关键字参数分别是什么？

位置参数：按位置传入，如 f(1, 2)。

关键字参数：按参数名传入，如 f(a=1, b=2)。

默认参数：定义时给默认值，如 def f(a=1)。

可变位置参数：*args，接收任意多个位置参数，打包成 tuple。

可变关键字参数：**kwargs，接收任意多个关键字参数，打包成 dict。


2.*args 和 **kwargs 的区别是什么？它们在函数定义和函数调用中分别有什么作用？

*args：函数定义中收集多余位置参数为 tuple；函数调用中解包可迭代对象。

**kwargs：函数定义中收集多余关键字参数为 dict；函数调用中解包字典。

定义时收集，调用时解包。

3.lambda 和普通 def 函数有什么区别？lambda 有什么限制？

lambda 是匿名函数，只能写一个表达式，不能写多条语句，不能有 return。

def 可以写复杂逻辑、文档字符串、装饰器。

lambda 适合简单回调，如 sorted(key=...)。

4.解释 Python 的 LEGB 作用域规则。

L：Local，当前函数局部作用域。

E：Enclosing，外层函数作用域。

G：Global，模块全局作用域。

B：Built-in，内置作用域。


5.什么是闭包？构成闭包需要哪三个条件？
内层函数引用了外层函数的变量，并且外层函数返回内层函数，内层函数在外层函数执行结束后仍能访问这些变量。
三个条件：

有嵌套函数。

内层函数引用外层变量。

外层函数返回内层函数。

6.global 和 nonlocal 的区别是什么？
global：声明变量来自模块全局作用域。

nonlocal：声明变量来自外层函数作用域。

nonlocal 不能用于全局变量。

7.装饰器的本质是什么？为什么说装饰器本质上是“函数作为参数、返回新函数”？
装饰器本质是一个可调用对象，接收函数作为参数，返回一个新函数。
它可以在不修改原函数代码的情况下，增加日志、计时、重试、缓存等功能。

8.functools.wraps 的作用是什么？不加它会出现什么问题？
functools.wraps 把原函数的 __name__、__doc__、__module__、__annotations__ 等元数据复制到 wrapper 上。
不加它，被装饰后的函数名字会变成 wrapper，文档丢失，调试和框架识别会出问题。

9.函数在 Python 中是“一等对象”吗？这意味着什么？
是。函数可以赋值给变量、作为参数传入、作为返回值返回、放入容器。
这意味着 Python 支持高阶函数和装饰器
